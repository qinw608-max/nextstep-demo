03 / SYSTEM

少一点魔法，多一点可追踪。

当前桌面版由 Electron、React、TypeScript、Zustand 与 React Flow 构建。画布数据保存在本地 JSON，MCP Bridge 提供外部调用入口。

LOCAL FIRST工作数据优先保留在本地。
VISIBLE STATE节点明确显示来源、状态和执行变化。
REVERSIBLE关键操作可以撤销、保存和恢复。
SMALL STEPS每次只解决一个明确问题，并保留验收路径。
