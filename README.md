# NextStep

NextStep 是位于 Agent 工具旁边的本地执行画布，让长任务的过程可见、可追踪、可沉淀。

它不替换 Agent，也不把执行过程简化成一条对话流。任务、文件、决定、批注和 Agent 写入都可以回到对应节点，最终收归为可复用的工作结构。
